# 業務流程文件

## 1. 管理員操作流程

### 1.1 會員管理
登入 → 會員列表 → 新增/編輯會員 → 查看會員詳情

text

### 1.2 為客戶購買組合包
會員詳情 → 點擊「購買組合包」
→ 選擇客戶（自動帶入）
→ 選擇組合包模板
→ 輸入購買總次數、購買日期
→ 確認購買
→ 自動跳回會員詳情（顯示新組合包）

text

### 1.3 為客戶使用服務（扣次）
會員詳情 → 點擊「使用組合包」/「使用傳統服務」
→ 選擇要使用的方案
→ 勾選服務項目（組合包可多選）
→ 填寫備註（選填）
→ 點擊灰色簽名區
→ 進入滿版簽名頁
→ 簽名 → 確認
→ 自動返回會員詳情（顯示簽名預覽）
→ 點擊「確認使用」
→ 完成扣次

text

### 1.4 調整次數（人工補償）
會員詳情 → 點擊「調整次數」
→ 輸入調整數量（正數增加、負數減少）
→ 填寫原因
→ 送出
→ 記錄寫入 adjustments 表

text

### 1.5 查看使用紀錄
側欄 → 會員使用紀錄
→ 篩選客戶姓名
→ 查看卡片列表
→ 點擊簽名圖片可放大
→ 點擊「編輯」可修改備註

text

## 2. 客戶操作流程

### 2.1 登入
首頁 → 會員登入
→ 輸入手機號碼、密碼
→ 登入成功 → 我的療程包頁面

text

### 2.2 查看我的療程包
我的療程包（只顯示有剩餘次數的）
├── 傳統服務包：服務名稱、剩餘次數、購買日期
└── 組合包：名稱、剩餘總次數、購買日期、包含項目

text

### 2.3 查看使用紀錄
導航 → 使用記錄
└── 卡片列表（傳統/組合包/贈品）
├── 使用項目明細
├── 贈品資訊
└── 簽名圖片（點擊放大）

text

### 2.4 查看歷史購買
導航 → 歷史購買
├── 傳統服務包（已用完）
└── 組合包（已用完）+ 包含項目

text

## 3. 安全機制

### 3.1 冪等性（Idempotency）
- 所有扣次 API 要求攜帶 `X-Idempotency-Key` header
- 後端檢查 key 是否已存在，若存在則拒絕重複請求
- 防止因網路不穩導致重複扣次

### 3.2 角色權限
| 角色 | 權限 |
|------|------|
| admin | 全部功能 |
| staff | 使用服務、查看記錄 |
| customer | 查看自己的療程包、使用記錄、歷史購買 |

### 3.3 簽名儲存策略
- 傳統服務：上傳到 Supabase Storage → 存 URL
- 組合包：base64 → 自動轉換 → 上傳 Supabase Storage → 存 URL
- 資料庫僅存 URL（約 100 字元），圖片存在 Storage
